# consulta-meteorologica
Projeto desenvolvido durante o curso de Desenvolvimento Front-End do programa Bolsa Futuro Digital do Instituto Hardware BR.

## Objetivo
Desenvolver uma aplicação Front-End que integre comunicação assíncrona com uma API pública, manipulação do DOM e armazenamento local.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- LocalStorage
